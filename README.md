# H ETF Magazine — November 2026

현대차증권 H ETF Magazine 2026년 **11월호 (Vol.11)** 웹 매거진입니다.

## 웹사이트

- [H ETF Magazine 11월호 바로가기](https://hmsecetf.github.io/H-ETF-Magazine/)
- GitHub 저장소: https://github.com/HMSECETF/H-ETF-Magazine

> 이 저장소는 프로젝트 사이트(Project Pages)입니다. `https://hmsecetf.github.io/`는 별개의 사용자 사이트 주소이므로 자동으로 이 매거진을 표시하지 않습니다.

## 파일 구성

- `index.html` — 웹사이트 본문. 11월호 12개 페이지 이미지가 HTML 안에 포함되어 있어 이 파일만으로도 웹사이트를 열 수 있습니다.
- `magazine.pdf` — 원본 PDF를 별도로 공개하려는 경우에 쓰는 선택 사항 파일입니다. 필요하면 최신 11월호 PDF로 함께 교체합니다.
- `README.md` — 이 프로젝트 설명 파일입니다. 웹사이트 화면에는 표시되지 않습니다.

## 월별 업데이트 방법

1. 새 월호용 `index.html`을 만들어 이 저장소 최상위에 업로드하고 기존 파일을 교체합니다.
2. `magazine.pdf`를 별도로 제공한다면 최신 PDF로 함께 교체합니다.
3. `README.md`의 월호와 안내를 수정합니다.
4. `main` 브랜치에 커밋한 뒤 GitHub Actions의 **pages build and deployment** 성공 여부를 확인합니다.
5. https://hmsecetf.github.io/H-ETF-Magazine/ 를 열고 강력 새로고침(`Ctrl + Shift + R`)하여 확인합니다.

## GitHub Pages 설정

`Settings` → `Pages` → `Build and deployment`에서 `Deploy from a branch`, `main`, `/(root)`를 사용합니다.

## 안내

웹사이트의 ETF 관련 정보는 매거진에 기재된 기준일을 따릅니다. 최신 상품정보와 위험사항은 투자설명서 및 공식 공시를 확인하시기 바랍니다.
